# План: Админ-панель с 2FA

## Контекст
- Проект: Minsk Gastro Guide (FastAPI + React + PostgreSQL)
- Аккаунт админа: `asasin.leha@yandex.ru` (уже зарегистрирован)
- 2FA коды отправляются на `asasin.leha@yandex.ru` (меняем RESEND_TO_EMAIL)
- Авторизация через localStorage + JWT без React Context

---

## Шаг 1: Бэкенд — модель User + миграция

**Файл: `backend/models.py`**
- Добавить колонку `is_admin = Column(Boolean, default=False)` в класс `User`
- Добавить колонку `admin_code = Column(String(10), nullable=True)` для хранения 2FA кода
- Добавить колонку `admin_code_expires = Column(DateTime, nullable=True)` для таймера кода

**Файл: `backend/main.py`** (миграция в начале файла)
- Добавить `ALTER TABLE users ADD COLUMN IF NOT EXISTS is_admin BOOLEAN DEFAULT FALSE`
- Добавить `ALTER TABLE users ADD COLUMN IF NOT EXISTS admin_code VARCHAR(10)`
- Добавить `ALTER TABLE users ADD COLUMN IF NOT EXISTS admin_code_expires TIMESTAMP WITH TIME ZONE`

---

## Шаг 2: Бэкенд — охранник `get_current_admin`

**Файл: `backend/auth.py`**
- Новая функция `get_current_admin`: вызывает `get_current_user`, затем проверяет `user.is_admin == True`
- Если не админ → HTTP 403 Forbidden

---

## Шаг 3: Бэкенд — Modified Login + 2FA endpoints

**Файл: `backend/schemas.py`**
- Новая схема `AdminVerifyCode`: `{ email: str, code: str }`

**Файл: `backend/main.py`**
- Изменить `POST /api/login`:
  - Если `db_user.is_admin == True`: НЕ выдавать JWT сразу
  - Вместо этого: генерировать 4-значный код, сохранять в `admin_code`, отправлять на `admin_code_expires` (15 мин), отправлять через Resend
  - Возвращать `{ "requires_2fa": true, "email": email }`
  - Если обычный юзер — всё как раньше

- Новый `POST /api/admin/verify-2fa`:
  - Принимает `{ email, code }`
  - Проверяет код и срок действия
  - Если ОК → выдаёт JWT (как обычный логин) + `{ "access_token", "token_type", "user_name", "is_admin": true }`
  - Если НЕ ОК → 401

- Новый `POST /api/admin/send-2fa-code`:
  - Повторная отправка кода (для кнопки "Отправить код повторно")
  - Проверяет что пользователь — админ, генерирует новый код

---

## Шаг 4: Бэкенд — Admin API endpoints

**Файл: `backend/main.py`**

- `GET /api/admin/bookings` — все бронирования (Depends: get_current_admin)
- `PATCH /api/admin/bookings/{id}/status` — изменение статуса брони (active/cancelled)
- `GET /api/admin/messages` — все сообщения (контакты + поддержка)
- `GET /api/admin/export/bookings` — CSV экспорт бронирований (Response с text/csv, Content-Disposition header)
- `GET /api/users/me` — добавить поле `is_admin` в ответ (обновить UserResponse в schemas.py)

---

## Шаг 5: Фронтенд — изменение логина (2FA flow)

**Файл: `frontend/src/pages/LoginPage.tsx`**
- После успешного POST `/api/login` проверять `data.requires_2fa`
- Если `true` → показывать дополнительный экран ввода 4-значного кода
- При вводе кода → POST `/api/admin/verify-2fa`
- При успехе → сохранять `token`, `userName`, `isAdmin: true` в localStorage, редирект на `/admin`
- Кнопка "Отправить код повторно" → POST `/api/admin/send-2fa-code`

## Верификация

1. Запустить бэкенд: `cd backend && uvicorn main:app --reload`
2. Запустить фронтенд: `cd frontend && npm run dev`
3. Войти как `asasin.leha@yandex.ru` → должен появиться экран 2FA
4. Проверить почту → ввести код → попасть в `/admin`
5. Обычный юзер → логинится как обычно, кнопка "Админка" не видна
6. Вбить `/admin` вручную → редирект на 404
7. В админке проверить все 3 вкладки
8. Скачать CSV → открыть в Excel
